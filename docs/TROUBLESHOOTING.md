# Troubleshooting

- **Opening workspace never finishes:** if Firebase cannot initialize, use the explicit guest option or retry. Account-cached history stays hidden. If IndexedDB is unavailable (private mode/storage restriction), enable site storage or use a normal browser profile. Do not clear old localStorage before exporting it; migration leaves it as a recovery source.
- **Google sign-in unauthorized-domain:** add the exact hostname, not a URL path, in Firebase Authentication authorized domains. `localhost` may need explicit addition. Allow the provider popup; use a normal browser if an embedded browser blocks Google consent. Real production consent needs a final check on the deployed hostname.
- **Cloud controls are unavailable:** production cloud is deliberately off until dedicated rules/config are verified. Use local JSON backups. Do not replace another app's rules to make the button appear.
- **Sync conflict:** export a backup first, then choose which device's version to retain. A sync error retains local pending changes. A downloaded change may require a reload to refresh visible views. Never reload during a workout solely to resolve a sync message.
- **Camera denied/missing:** use HTTPS or localhost, allow this site's camera permission in browser settings, close other camera apps and select front/back before starting. No camera frames are uploaded.
- **Model failure/WebGL unavailable:** check Settings offline downloads and reload after finishing any active session. Enable browser hardware acceleration/use a supported current browser; a low-end device may not support the legacy pose engine. Rehearsal remains available. Do not interpret rehearsal as measured movement.
- **Angles move but reps do not:** begin at the configured start endpoint, hold briefly, reach the turn endpoint and return. Required joints must stay confidently visible. Squats/hinges check another joint. A sudden camera move, low confidence or long processing gap cancels a partial cycle. Use only a comfortable approved range.
- **Video rejected:** use a browser-playable codec (commonly H.264 MP4), under 150 MB and 15 minutes. Video analysis is one continuous set and samples 100 ms video-time steps; it is not a claim of frame-by-frame clinical analysis. Very fast movements between sampled frames may be missed. Try a shorter, slower clip.
- **Device speech sounds different/offline speech unavailable:** choose an installed English voice in Settings or use captions. Browser/OS voices can require network access. Speech speed/voice selection configure device speech; Piper uses its separate local voice model. The app does not promise a human voice.
- **Local AI unavailable:** start `./start-local.command`, verify Ollama has the configured model, and use port 8766. A static website cannot use your computer's loopback service. If model responses are slow, cancel and use the device guide. Do not act on generated medical advice.
- **Offline downloads interrupted:** retry in Settings while connected; completed revisioned files are reused. Browser quota/eviction can remove assets. Data exports are your recovery copy; installation is not a cloud backup.
- **Old UI after deploy:** finish your workout and use the app-update banner. Reload after the new worker activates. Rebuild `dist` before deploying. Do not delete browser data just to refresh styles.
- **History appears empty:** check active account/profile, date range and source filter. Rehearsals are excluded from tracked statistics; the summary's View history action includes them.
- **Reminders:** the planner exports an ICS file. Import it into a calendar app; calendar permissions and reminder delivery belong to that app. KinArc does not provide background push notifications.
